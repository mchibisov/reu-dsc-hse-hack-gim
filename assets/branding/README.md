# Оформление VK-бота

- `avatar.png` — аватарка. Установить вручную через фото сообщества из аккаунта администратора: VK отклоняет `photos.getOwnerPhotoUploadServer` с токеном сообщества (код 27).
- `welcome.png` — приветствие «История начинается с вас». Загружено в VK и прикрепляется к первому приветствию новой анкеты, без дополнительных сообщений на каждом шаге.
- `directions.png` — дополнительная карточка пяти направлений, для презентации или ручной отправки. Автоматически не рассылается.

Изображения созданы встроенным imagegen. Задание: бордово-красная и кремовая музейная стилистика, архитектура ГИМ, волонтёры, читаемые русские заголовки. Это оформление демонстрационного проекта, а не утверждённая музеем айдентика.

Ссылка на картинку в `config/vk-branding.json` привязана к ID сообщества: при самостоятельном запуске в другом сообществе она не используется. Удаление файла конфигурации отключает картинку и сохраняет текстовое приветствие.
