# Общая PostgreSQL-версия

Основное решение находится в `main`: PostgreSQL в Supabase, SQL-очередь, без Redis и ARQ.

Единая актуальная инструкция перенесена в [README](README.md). Команды `python -m gim.shared_main`, `setup_shared.cmd`, `run_shared.cmd` и `docker compose -f compose.shared.yaml up --build -d` продолжают работать.
