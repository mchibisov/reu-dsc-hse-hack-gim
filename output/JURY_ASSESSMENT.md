# Оценка MVP ГИМ по критериям жюри и IT

Историческая самооценка до очистки. Актуальные доказательства запуска,207тестов, Docker и границы живого VK — [повторная техническая приёмка S009](S009_TECHNICAL_RECHECK.md); старые баллы ниже не являются результатом новой приёмки.

Дата оценки: 22 октября 2026 года.

**Общая оценка: около 7/10 как MVP для хакатона.** Сильная сторона — работающая цепочка и удобство куратора. Главная слабость — пока не доказанная близость новых оценок к экспертным. Для постоянной эксплуатации музеем остаются организационные и эксплуатационные задачи.

Это техническая самооценка, **не прогноз баллов жюри**. Официальные критерии имеют шкалы «Да/Нет», 1–5 и 1–3; ниже все оценки переведены в десятибалльную шкалу.

## Будут ли вопросы «как запустить»?

**Да — и сейчас они обоснованны.**

Для обычного пользователя всё просто: **[открыть бота](https://vk.me/club242476311) → «Начать»**. Для сотрудника дополнительно нужна назначенная роль.

Для IT-специалиста запуск на новой инфраструктуре сложнее: нужны подключения Supabase, миграции, три роли БД, музейный банк вопросов, набор, VK Callback, Polza и расписание восстановления задач.

### Противоречия в основном README на момент оценки

- Описан Long Poll, хотя действующий облачный запуск использует Callback.
- Указано старое количество миграций.
- Ручная оценка названа отсутствующей, хотя уже реализована.
- Остались старые сведения о рубрике и разбиении исторических данных.
- Локальный volume описан без ясного отделения от облачного хранения.

Поэтому **оценка документации воспроизводимого запуска — 6/10**. Актуальная [инструкция развёртывания](../docs/deployment-guide.md) есть, но главный README нужно привести к ней.

## Что доделать в первую очередь

1. **Исправить README и проверить чистый запуск по нему.** Это наиболее заметная и быстро устранимая проблема для IT-жюри.
2. **Провести два живых прохождения на телефонах:** разные направления, персональные вопросы, уведомление, карточка и скачивание Excel.
3. **Измерить действующую формулу на независимых данных** и честно представить результат.
4. **Перед настоящим музейным набором:** регулярные внешние резервные копии, мониторинг и правила работы с персональными данными.

## Ответ о запуске для защиты

> Бот уже развёрнут в облаке: кандидату достаточно открыть ссылку VK. Для переноса предусмотрены Docker и облачная инструкция; потребуются собственные ключи VK и Polza, база Supabase и настройка обработчика событий. Секреты в репозиторий не входят.
