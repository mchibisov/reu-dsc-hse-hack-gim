## Обязательное по QA и описанию кейса

| Требование | Реализация и проверка |
|---|---|
| VK, старт и понятный сценарий | Личные сообщения сообщества, кнопка старта, меню и прогресс. Это штатный тип VK-бота; отдельный пользовательский аккаунт не требуется |
| Полная анкета, все обязательные поля | 19 музейных вопросов; неприменимое поле отмечается явно. Согласие до персональных ответов; полная дата и 18+; каждый ответ сохраняется |
| Адресные AI-уточнения | DeepSeek, история ответов, направление, цитата, контроль повторов, максимум три. Библиотечный fallback |
| Предварительная оценка и ранжирование | Серверная формула 50/35/15 по дополнению пользователя; цитаты проверяются. Старая рубрика закреплена за старыми анкетами |
| Исторические экспертные оценки | 112 анкет изучены; независимый контроль прежних подходов проведён. Значимого выигрыша над majority baseline нет; новая пользовательская формула не выдаётся за независимо валидированный предиктор |
| Данные о специфике программы | Описания из музейного PDF; проверка совпадения ожиданий; для инклюзии отдельный отбор и обучение. 100 участников не ограничивают число заявок |
| Куратор видит результат и может исправить | Карточки, резюме, цитаты, ограничения, направления, вопросы интервью; `/score` сохраняет исходный AI и автора изменения |
| Табличный экспорт одной анкеты и набора | `/export UUID`, `/export`, скрытый кодовый Excel; настоящая доставка XLSX через VK и скачивание проверяются отдельно от unit tests |
| Микро- и макроаналитика | Карточка и Excel одной анкеты; `/stats`, рейтинг, распределения оценок/направлений в сводке |
| Сохранение и восстановление | Supabase PostgreSQL, SQL-очередь, дедупликация, аренды и повторы; восстановление резервного снимка проверено |
| Около 50 одновременно | 50/50 синтетических пользователей на локальной SQL-очереди; это не нагрузочный тест 50 реальных вызовов VK/LLM |
| Собеседование и окончательное решение | Принимает сотрудник. Автоматического приглашения или отказа нет |

## Уточнения и ограничения

- Веса и формула не утверждены жюри: это явное дополнение пользователя. Из пяти музейных групп три участвуют в новой формуле; качество анкеты, логистика и пробелы остаются материалом для проверки сотрудником. Закрытость профиля и неподтверждённые личные предположения не используются.
- При сбое LLM анкета остаётся сохранённой, фиктивный 0 не подставляется. Нет оценки до успешного анализа/оценки сотрудника.
- Полноценный PDF, Google Sheets, отдельный веб-кабинет и просмотр профиля — необязательные идеи, не функции выпуска.
- Браузерная приёмка VK не выполнена из-за ранее установленного ограничения Computer Use. Подписанный синтетический Callback, настоящий API VK, Supabase и скачивание файлов — отдельные доказательства, не подмена человеческого UI-теста.
- Готовность к хакатону и технический запуск не равны гарантии бессрочной эксплуатации без сопровождения: нужны оператор, контроль квот, резервные копии и согласованные музеем правила хранения/удаления данных.
