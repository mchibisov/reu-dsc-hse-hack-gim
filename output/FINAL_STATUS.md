# Фактический статус — 22.10.2026

## Что запущено

- [Открыть бота](https://vk.me/club242476311) · [страница запуска](https://gim-volunteer-bot.vercel.app).
- Vercel Callback API подтверждён VK, сервер №2 включён. Supabase PostgreSQL и Polza DeepSeek остаются рабочими сервисами.
- Локальные gateway/worker контролируемо остановлены при переносе за 4,1с; последний Long Poll cursor обработан мостом. Docker-образ и volume сохранены для отката. Компьютер больше не является рабочим сервером бота.
- В облаке четыре SQL-обработчика под одной арендой, минутный recovery Cron и приватное хранение XLSX в PostgreSQL. Бесплатное размещение ограничено квотами провайдеров; Polza использует существующий оплачиваемый API-баланс.

## Что реально проверено

- Старый полный сценарий двух контрастных синтетических кандидатов: по 23 сохранённых ответа, персональные уточнения, проверка ожиданий, настоящие Supabase/DeepSeek, реальные уведомления сотруднику, два скачанных и сверенных XLSX; обычный и кодовый экспорт.
- Дополнительный полный прогон новой формулы завершён после исправления reasoning: два контрастных кандидата, по 23 ответа, три группы критериев, реальные уведомления, два скачанных и проверенных XLSX, включая скрытый кодовый экспорт.
- Новая формула на двух синтетических профилях через настоящий Polza: S=2.415 и 1.830, оба балла 2; 13 фиксированных признаков, три группы. Время анализа 65,59с и 15,88с. Это не измерение качества относительно экспертов. Дополнительный сквозной прогон выявил обрыв reasoning на 6000 токенах; для новой формулы и персональных уточнений reasoning отключён, модель сохранена. На том же проблемном профиле проверенный JSON получен за 15,44с, 1607 выходных токенов, S=2.355.
- Ручная оценка синтетической анкеты через сервис/реальную БД сохранила исходный AI-балл; собственный сброс создал новую попытку и архивировал старую. Уведомления отправлены только уполномоченному тестовому сотруднику.
- В облаке: авторизованный подписанный синтетический Callback `/status` → очередь → реальный ответ VK; `/export` → файл через VK → скачивание и открытие пяти листов XLSX. ACK: 1,633с и 1,218с. Вложение 31 665 байт; числовой рейтинг присутствует. Это API-приёмка, а не человеческое прохождение в браузере.
- 112 анкет из новых ссылок организатора совпадают по содержательным полям и меткам с локальными данными: 57 + 55.
- 178 тестов приложения (один платформенный skip) и 49 тестов PostgreSQL прошли. Регрессионные тесты покрывают поздние и быстрые фрагменты, дедупликацию транспорта, права, кодовый Excel, поломку LLM, сохранение валидного базового анализа при сбое дополнительного отчёта, архивирование, новую формулу и immutable XLSX.
- Восстановление приватной резервной копии реальной БД проверено на отдельной локальной PostgreSQL с равенством исходных данных.

## Честные границы готовности

Нельзя утверждать, что буквально весь первоначальный план выполнен без ограничений. Независимый контроль прежнего гибрида: accuracy 45,5%, MAE 0,857; прежний production 40,9%, MAE 0,714; majority baseline 50%. Обученный гибрид не включён. Новая пользовательская формула 50/35/15 не выдаётся за доказанное улучшение точности.

Не выполнены: человеческая браузерная приёмка VK; нагрузка 50 реальных одновременных VK/LLM-вызовов; регулярные автоматические backups с проверяемым SLA. Локальная очередь выдержала 50/50 синтетических пользователей (p95 0,845с), но эта метрика не включает внешний API.

Четыре старые завершившиеся ошибкой задачи от 21.10 оставлены для аудита, не перезапущены вслепую ради устранения счётчика. Их старый код сохранил только RuntimeError, поэтому точную первопричину задним числом доказать нельзя. Современные отправка/экспорт повторно проверены. Неоконченные заявки и очередь не удалялись.

Аватар подготовлен в `assets/vk-avatar.png`; VK требует иной тип авторизации для загрузки owner photo (`vk_27`). Название «Волонтёры ГИМ | бот», сообщения, старт и кнопки обновлены официальным API. Надпись «Сообщество» контролирует VK.

Для публичной эксплуатации музею необходимы согласованные правила хранения/удаления и оператор персональных данных; текущий запрос `/delete` честно направляет к оператору. Нельзя обещать полностью бессрочную эксплуатацию без сопровождения, контроля квот и утверждения этих правил. PDF/Google Sheets и просмотр профиля не реализованы и не являются обязательными функциями QA.
