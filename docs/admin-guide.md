# Куратору ГИМ

Откройте [бота](https://vk.me/club242476311). Это личные сообщения сообщества VK — штатный способ работы VK-ботов. Роль сотрудника оператор назначает вашему VK ID; знание экспортного кода эту роль не даёт.

| Действие | Команда |
|---|---|
| Меню | `/admin` |
| Новые поданные анкеты | `/new`, следующая страница `/new 2` |
| Рейтинг с AI-сводками | `/top`, `/top 2` |
| Карточка и доказательства | `/application UUID` — готовая команда есть в уведомлении и рейтинге |
| Статистика | `/stats` |
| Excel набора / одной анкеты | `/export` / `/export UUID` |
| Изменить балл | `/score UUID 2 Подробная причина изменения` |
| Состояние задач | `/jobs` |
| Новая собственная тестовая попытка — только admin | `/reset`, затем `/reset confirm` |

После завершения приходит **«+1 анкета»**. После успешного фонового анализа — второе уведомление с краткой AI-сводкой. Карточка содержит предварительный балл, расчёт, цитаты, фиксированные факты по пяти группам, сильные стороны, ограничения и недостающие сведения, соответствие направлениям и вопросы для собеседования. «Недостаточно данных» не означает «нет навыка». Балл и доля подтверждённых сведений — разные показатели, не вероятность приёма.

Окончательное решение принимает сотрудник. Независимое качество новой модели не превысило baseline; она не включена автоматически. Действующая рубрика предварительная, её веса не утверждены музеем. Оценку проверяйте по ответам. Ручное изменение сохраняет причину и автора отдельно от исходного AI-результата; исходный AI-балл остаётся в карточке и Excel. Отсутствие оценки при сбое модели не означает 0.

**Excel приходит отдельным вложением**, после сообщения о подготовке. Листы: «Анкеты» — рабочий список, «Ответы» — полная история, «Собеседование» — полный отчёт и ожидания, «Сводка», «Оценка» — факты и цитаты. Есть фильтры, закрепления и переносы; длинный текст можно раскрыть в строке формул/увеличить высоту строки. Полный исходный AI-отчёт и технический JSON сохранены в скрытых технических колонках, рабочий список показывает короткое резюме. Очень длинные значения продолжаются на следующих строках с номерами частей.

Секретную команду `/excel КОД` оператор передаёт отдельно уполномоченному получателю. Она выдаёт Excel текущего набора, не открывает карточки и меню сотрудника. Код не публикуется и не включается в видео; после пяти неверных попыток действует 10-минутная блокировка. Архивные тестовые попытки не входят в обычную и кодовую выгрузки; сотрудник может открыть известный UUID архивной анкеты для аудита.

Сброс создаёт новую **собственную** тестовую попытку. Предыдущие ответы, оценки, файлы и аудит сохраняются в архиве; чужие анкеты не меняются. `/start` продолжает текущую попытку. `/delete` не выполняет полного удаления: запрос на удаление данных обрабатывает оператор.
