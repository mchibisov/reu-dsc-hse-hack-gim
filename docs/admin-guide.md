# Руководство администратора и куратора

Откройте [бота ГИМ](https://vk.me/club242476311), разрешите сообщения и отправьте `/admin`. Для своей установки используйте ссылку вашего сообщества. Бот работает в личных сообщениях сообщества VK.

## Ежедневная работа

| Задача | Команда |
|---|---|
| Открыть меню | `/admin` или «Помощь» |
| Новые завершённые заявки | `/new`, `/new 2` |
| Рейтинг и краткие AI-сводки | `/top`, `/top 2` |
| Полная карточка кандидата | `/application UUID` — готовая команда есть в уведомлении и списке |
| Статистика набора | `/stats` |
| Excel всех анкет / одного кандидата | `/export` / `/export UUID` |
| Сохранить оценку сотрудника | `/score UUID 2 Обоснование изменения` |
| Состояние обработки | `/jobs` |

После завершения анкеты приходит **«+1 анкета»**. Когда готов анализ — уведомление с предварительным баллом и AI-сводкой. Отчёт включает расчёт оценки, подтверждающие цитаты, мотивацию, опыт, занятость, полезные навыки, пробелы, соответствие направлениям, результат проверки ожиданий и вопросы для собеседования.

Оценка предварительная: решение о приглашении принимает сотрудник. «Недостаточно данных» означает необходимость уточнения, а не отсутствие навыка. Индикаторы показывают подтверждённые признаки, а не вероятность приёма. В рейтинге используется дробный балл S по формуле 50/35/15; целая оценка округляется от 0.5 вверх. Ручной балл сотрудника имеет приоритет. При ручной корректировке сохраняются автор и причина, исходный AI-результат остаётся в истории и Excel.

Формула задана командой: музей её отдельно не утверждал, независимая точность новой формулы не подтверждена. Прежние анкеты сохраняют свою рубрику. При сбое LLM анкета остаётся сохранённой без фиктивного нуля; сотрудник получает уведомление.

## Как добавить администратора или куратора

Это действие доступно **только действующему администратору**, прямо в диалоге бота. База данных и операторский пароль не нужны.

1. Получите и проверьте **числовой VK ID** сотрудника. Имя и короткий адрес вроде `vk.ru/name` вместо числа не подходят. Не назначайте доступ непроверенному аккаунту.
2. Для куратора отправьте `/staff add 123456789 curator`.
3. Для администратора отправьте `/staff add 123456789 admin`.
4. Бот подтвердит ID и роль. Новый сотрудник открывает сообщения сообщества, разрешает их и отправляет `/admin`. Без разрешения сообщений VK не доставляет уведомления.

Число `123456789` — пример, замените его проверенным ID сотрудника. `/staff` показывает форматы команд.

**Куратор** видит анкеты и Excel, может корректировать оценку. **Администратор** дополнительно управляет сотрудниками и собственной тестовой попыткой. Знание кода Excel не даёт ни одной из этих ролей.

Отозвать доступ и уведомления: `/staff remove 123456789`. Последнего администратора удалить нельзя. При передаче сначала назначьте администратора ГИМ и проверьте его вход, затем отзовите доступ команды. Изменения ролей записываются в аудит.

**Первый администратор:** в быстром Docker-запуске задаётся через `ADMIN_VK_ID`; на новой внешней БД создаётся оператором командой `bootstrap_admin.py` из [инструкции подготовки](setup-from-scratch.md). Повторный bootstrap не обходит уже существующих администраторов.

## Excel

После `/export` приходит сообщение о подготовке, затем отдельное вложение `.xlsx`. Откройте его в Excel или LibreOffice:

- **Анкеты:** рабочий список с фильтрами, рейтингом, направлениями и краткой сводкой.
- **Ответы:** исходные ответы, персональные уточнения и ответы на них.
- **Собеседование:** ФИО и подготовленные вопросы для очного интервью. Совпадение ожиданий и исходные ответы смотрите в «Ответах», резюме — в «Анкетах».
- **Сводка:** количество и распределения.
- **Оценка:** факты, цитаты и показатели по группам.

Заголовки закреплены, текст переносится; очень длинные ответы продолжаются отдельными пронумерованными частями. Технические поля скрыты или расположены в конце. Значения защищены от интерпретации как формулы.

Скрытый `/excel КОД` передаётся только уполномоченному получателю отдельно: он разрешает выгрузку, но не административные команды. В обычном меню кода нет. Неверные попытки ограничены; код не сохраняется в ответах и логах.

## Повторное тестирование

Администратор отправляет `/reset`, затем `/reset confirm` и «Начать». Создаётся новая **собственная** попытка. Прежние ответы, оценки, файлы и аудит архивируются и сохраняются. Чужие анкеты не меняются. Для продолжения незавершённой анкеты достаточно `/start`.

## Эксплуатация и данные

Рабочий облачный бот не требует включённого компьютера. Оператор контролирует квоты Vercel/Supabase, баланс Polza и очередь. Запросы на удаление персональных данных обрабатываются администрацией сообщества по принятому музеем регламенту: `/delete` сообщает этот порядок и не стирает аудит автоматически.

[Передача и эксплуатация в ГИМ](transfer-to-gim.md) · [Запуск Docker](docker-quickstart.md) · [Руководство кандидата](user-guide.md)

В листе «Ответы» показаны ФИО и только актуальные ответы, сгруппированные по кандидату. Технические идентификаторы скрыты; версии ответов сохраняются в БД. Лист «Собеседование» содержит вопросы для интервью, без повторной AI-сводки.
