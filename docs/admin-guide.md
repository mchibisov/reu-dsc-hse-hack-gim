# Куратору ГИМ

Откройте [бота](https://vk.me/club242476311). Это личные сообщения сообщества VK — штатный способ работы VK-ботов. Роль сотрудника оператор назначает вашему VK ID; знание экспортного кода эту роль не даёт.

| Действие | Команда |
|---|---|
| Меню | `/admin` |
| Новые поданные анкеты | `/new`, следующая страница `/new 2` |
| Рейтинг с AI-сводками | `/top`, `/top 2` |
| Карточка и доказательства | `/application UUID` — готовая команда есть в уведомлении и рейтинге |
| Статистика | `/stats` |
| Excel набора / одной анкеты | `/export` / `/export UUID` |
| Изменить балл | `/score UUID 2 Подробная причина изменения` |
| Состояние задач | `/jobs` |
| Новая собственная тестовая попытка — только admin | `/reset`, затем `/reset confirm` |

После завершения приходит **«+1 анкета»**. После успешного фонового анализа — второе уведомление с краткой AI-сводкой. При окончательном сбое анализа приходит отдельное уведомление: анкета сохранена, оценка отсутствует, требуется проверка сотрудника.

**Профиль кандидата** показывает три индикатора: мотивация, опыт, занятость. Они строятся из сохранённых оснований оценки, без дополнительного обращения к модели. Это не вероятность приёма. Для прежней рубрики не показываются вымышленные проценты. Те же показатели есть в Excel; лист «Оценка» содержит полосы относительно максимума каждой группы.

Карточка содержит предварительный балл, расчёт, цитаты, фиксированные факты и цитаты, сильные стороны, ограничения и недостающие сведения, соответствие направлениям и вопросы для собеседования. «Недостаточно данных» не означает «нет навыка». Балл и доля подтверждённых сведений — разные показатели, не вероятность приёма.

Окончательное решение принимает сотрудник. Независимое качество новой модели не превысило baseline; она не включена автоматически. Для новых анкет включена явно заданная пользователем формула 50/35/15: мотивация 50%, опыт 35%, обучение и нагрузка 15%. Дробный S (0–3) определяет порядок в рейтинге; целый балл округляется с 0.5 вверх. Штраф применяется только при прямо подтверждённых исключительном интересе к фондам И отказе от альтернатив. Неизвестное означает неподтверждённый признак, а не отсутствие навыка. Веса не утверждены музеем; независимая точность этой новой формулы не измерена. Старые анкеты сохраняют старую рубрику и результаты. Ручной балл имеет приоритет при сортировке. Оценку проверяйте по ответам. Ручное изменение сохраняет причину и автора отдельно от исходного AI-результата; исходный AI-балл остаётся в карточке и Excel. Отсутствие оценки при сбое модели не означает 0.

**Excel приходит отдельным вложением**, после сообщения о подготовке. Листы: «Анкеты» — рабочий список, «Ответы» — полная история, «Собеседование» — полный отчёт и ожидания, «Сводка», «Оценка» — факты и цитаты. Есть фильтры, закрепления и переносы; длинный текст можно раскрыть в строке формул/увеличить высоту строки. Полный исходный AI-отчёт и технический JSON сохранены в скрытых технических колонках, рабочий список показывает короткое резюме. Очень длинные значения продолжаются на следующих строках с номерами частей.

Секретную команду `/excel КОД` оператор передаёт отдельно уполномоченному получателю. Она выдаёт Excel текущего набора, не открывает карточки и меню сотрудника. Код не публикуется и не включается в видео; после пяти неверных попыток действует 10-минутная блокировка. Архивные тестовые попытки не входят в обычную и кодовую выгрузки; сотрудник может открыть известный UUID архивной анкеты для аудита.

Сброс создаёт новую **собственную** тестовую попытку. Предыдущие ответы, оценки, файлы и аудит сохраняются в архиве; чужие анкеты не меняются. `/start` продолжает текущую попытку. `/delete` не выполняет полного удаления: запрос на удаление данных обрабатывает оператор.

Бот размещён на [Vercel](https://gim-volunteer-bot.vercel.app). Постоянно держать компьютер включённым не требуется. Cloud Callback быстро подтверждает сохранённый запрос; четыре обработчика выполняют работу, Supabase Cron восстанавливает обработку после сбоя. При исчерпании бесплатных квот или недоступности провайдера возможны задержки: оператору доступны `/jobs` и инструкции развёртывания.
