# VK-бот ГИМ

Основа: схема пользователя из восьми таблиц. PostgreSQL/Supabase; без Redis и ARQ.
Python 3.12+, psycopg, httpx. Запуск Docker Compose: postgres, gateway, worker.
Один Long Poll-процесс на сообщество. Несколько асинхронных воркеров jobs.

## Границы
Бот ведёт основную анкету, сохраняет ответы, выбирает уточнения из подготовленного
набора и показывает реальные задачи направления. Тексты MVP-вопросов являются
адаптацией предоставленных заголовков, не утверждённым музеем окончательным банком.
Скоринг — внешний HTTP-сервис команды, без выдуманных критериев или запасного балла.
При недоступном скоринге анкета остаётся сохранённой, задача повторяется.
Excel включает все ответы, оценку и обоснования; доступ только сотрудникам.

## Поток
Long Poll -> транзакция inbox_events + jobs(kind=dialog) -> worker.
Диалог сериализован advisory lock по group_id/peer_id; отвечает через jobs(kind=send).
answers, applications и исходящие jobs фиксируются одной транзакцией.
Состояние и снимок вопросов хранятся в applications, перезапуск не теряет прогресс.
Завершение -> jobs(score), уведомления кураторов. Оценка -> evaluations.
Экспорт -> jobs(export) -> XLSX в общем Docker volume -> files -> загрузка VK.
Storage локальный с общим volume; интерфейс позволяет заменить его S3/Supabase Storage.

## Надёжность
Уникальность входящего (group_id,event_id), уникальные dedupe_key и vk_random_id.
jobs захватываются FOR UPDATE SKIP LOCKED с lease_token, lease_until и повторами.
Поздний worker не подтверждает чужую аренду. Последняя попытка становится failed,
включая падение процесса. События одного пользователя обрабатываются по порядку.
Стабильный random_id повторной отправки уменьшает дубли VK; абсолютную exactly-once
доставку во внешнюю систему не обещаем.
Роли и active проверяются в БД. Bootstrap сотрудников задаётся ADMIN_VK_IDS.
Команды /top, /export, /score, /stats, /notify доступны только сотрудникам.
По последнему указанию пользователя CONSENT_TEXT необязателен: пустое значение
начинает анкету сразу. Если текст задан, добавляется предварительный шаг согласия.

## Проверка
Тесты FSM: согласие, пустой ответ, направления, уточнения, завершение, повторный старт.
Тесты Excel: пользовательская строка не становится формулой, длинные ответы, кириллица.
Интеграционные тесты PostgreSQL: дедупликация, роли, обработка конкурентных событий,
перехват просроченной аренды, отказ устаревшему worker, сохранение анкеты и jobs.
Доступ к VK проверяется отдельно с настоящим токеном сообщества.
