# Проверка реализации

## Принятые решения
- Последнее указание пользователя: без Redis; PostgreSQL jobs вместо ARQ.
- FSM и выбор уточнений детерминированные. Генерация персонализированных вопросов
  через LLM остаётся интеграцией команды, не имитируется.
- Экспорты используют Docker volume; S3/Supabase Storage пока не подключён.
- Рабочая ветка: feat/vk-bot-storage-export; main не изменяется.

## TDD и review
FSM, экспорт, обработка VK и проверка оценок проверены сначала RED, затем GREEN.
Независимое review Superpowers выявило три Important проблемы:
1. Отзыв прав перед отправкой /top. Исправлено recipient_id и повторной проверкой роли.
2. Перестановка исходящих сообщений. Исправлено serial_key и глобальной sequence.
3. Устаревший worker публикует результаты. Исправлено fencing перед score/export
   и отдельным именем файла для каждой аренды.
Регрессионные тесты на все три воспроизвели ошибки до исправлений.
Дополнительный тест выявил пустой VK_GROUP_ID при миграции: исправлено.

## Среда
Docker CLI доступен, daemon отсутствует. Нативный временный PostgreSQL не смог
создать shared-memory segment из-за sandbox. SQL-проверки выполнены через
PGlite 0.5.10 по PostgreSQL wire protocol. Параллельные сессии проверяются отдельно
в GitHub Actions на PostgreSQL 17; локально этот тест явно пропускается.
Токен и сообщество VK не предоставлены; реальная доставка сообщений не проверена.
