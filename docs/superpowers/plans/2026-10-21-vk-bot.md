# VK-бот ГИМ Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline. Steps use checkbox syntax.

**Goal:** бот VK с PostgreSQL, устойчивой очередью и Excel-экспортом.
**Architecture:** один gateway принимает Long Poll; несколько worker обрабатывают jobs.
**Tech Stack:** Python, psycopg, httpx, PostgreSQL, Docker Compose.
**Spec:** ../specs/2026-10-21-vk-bot-design.md

## Global Constraints
- Восемь таблиц по схеме пользователя; без Redis/ARQ.
- Не придумывать критерии скоринга, не использовать результаты будущего участия.
- Не пушить в main; токены и реальные анкеты не помещать в git.

## Review Focus
- Дубль события не должен сохранять второй ответ.
- Два сообщения одного кандидата должны сохранять порядок.
- Падение последней попытки должно завершаться failed.
- Сотрудник с active=false не получает данные.
- Произвольный текст Excel не должен исполняться как формула.
