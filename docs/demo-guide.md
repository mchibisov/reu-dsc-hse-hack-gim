# Сценарий демонстрации

Подготовка: бот работает на Vercel, локальные gateway/worker запускать не нужно; секретный экспортный код и .env не попадают в кадр. Откройте [бота](https://vk.me/club242476311). Куратору нужна назначенная роль.

1. Кандидат: «Начать» → согласие → музейные вопросы. Покажите прогресс, кнопку своей ссылки VK и продолжение через `/start`.
2. Выберите медиа либо фонды. Бот объяснит реальные задачи: кандидат отвечает, подходят ли они и готов ли к альтернативам.
3. Покажите персональный AI-вопрос по предыдущему ответу. Завершите анкету и получите подтверждение сохранения.
4. Куратор: уведомление «+1 анкета», затем сообщение о готовом анализе. Откройте готовую `/application UUID`: минидашборд трёх групп, резюме, цитаты, неизвестные сведения, направления, интервью-вопросы и расчёт предварительной оценки.
5. `/score UUID 2 Уточнённая оценка сотрудника после проверки` — покажите сохранение исходного AI-балла.
6. `/export` → дождитесь вложения → откройте Excel. Покажите рабочий список, полные ответы, ожидания, доказательства, вопросы и сводку.
7. Администратор может повторить свой тест через `/reset` → `/reset confirm` → «Начать». Старую попытку не удаляет.

Для второго направления используйте другого добровольного тестировщика. Не выдавайте синтетический API-прогон за запись живого пользовательского диалога. Время 5–7 минут — ориентир, человеческий замер не подтверждён. На защите сообщайте честно: независимое улучшение точности не доказано; экспериментальный обученный классификатор не включён; новые анкеты используют заданную формулу 50/35/15, окончательное решение принимает сотрудник.
