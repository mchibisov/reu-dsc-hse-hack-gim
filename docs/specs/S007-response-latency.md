# S007 — задержка ответов VK без смены модели

Поручение пользователя 22.10.2026: бот отвечает через 20 секунд–3 минуты; модель менять нельзя. Пользователь подтвердил задержки и на обычных вопросах.

Цель: убрать блокировку обычного диалога и доставки медленным анализом/AI-вызовом, сохранить существующую модель, порядок событий, аренды, неизменяемые ответы и проверку цитат.

Критерии: (1) обычное событие, поступившее во время работающего медленного обработчика, исполняется и доставляется до его завершения; (2) в конце бюджета worker не откладывает все обычные события до нового запуска; (3) пустая очередь завершается быстро, без вечного spin; (4) полные unit/SQL проверки проходят; (5) отчёты и ограничения production-проверки сохранены. Не обещать конкретный production SLA без живых измерений.

Не менять модель/формулу и не запускать второй production gateway. Наличие локальных старых ключей не считать подтверждением доступа к действующей облачной конфигурации. Секреты/ответы кандидатов не выводить.
