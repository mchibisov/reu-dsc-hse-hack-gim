# S006 — проверка и исправление готовности основного решения

Основание: поручение пользователя от 22.10.2026 и приложенный HANDOFF (1).md. Продолжение существующего MVP, без нового продукта и изменения музейной рубрики.

## Цель и критерии приёмки

1. Актуальная main загружена без потери истории; проверяется именно она.
2. Установка зависимостей и миграций воспроизводится в чистом окружении Python 3.12 и отдельной PostgreSQL. Production, анкеты и внешние обработчики не меняются.
3. Проверяются приложение, private SQL-контракты, запуск CLI, импорт музейных материалов, анализ и XLSX на синтетических данных. Найденные дефекты устраняются с регрессионной проверкой.
4. Каждая проверка имеет отдельный отчёт и доказательства в results; результаты сопоставляются с IT-критериями без вымышленных баллов и обещаний экспертной точности.
5. Исправления публикуются в main обычным fast-forward push или разрешённым слиянием, без force и подмены автора; SHA сверяется с GitHub.

## Ограничения

Не менять облачный deployment, не запускать второй production gateway. Не подгонять алгоритм по просмотренным экспертным меткам. Человеческую мобильную приёмку и согласование музеем не заменять автоматическими тестами. Секреты и персональные данные в Git не включать.
