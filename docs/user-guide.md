# Как подать анкету

1. Откройте [бота ГИМ](https://vk.me/club242476311) и нажмите **Начать** (или отправьте `/start`). Нужен только аккаунт VK; отдельная регистрация и права администратора не нужны.
2. Прочитайте согласие. Если согласны, нажмите **Согласен** и отвечайте на вопросы по очереди. Основных вопросов 19. Для содержательных ответов обычно достаточно 1–3 предложений; для неприменимого поля напишите «не относится».
3. На вопрос о VK нажмите **Использовать мою страницу**. Также можно открыть присланную ссылку и отправить её в ответ.
4. После основной анкеты DeepSeek может задать до трёх коротких вопросов по вашим ответам. Это уточнение опыта и интересов, не экзамен. Ориентир на всю анкету — **7–8 минут**; фактическое время зависит от длины ответов и связи.
5. Дождитесь сообщения **Анкета получена. Спасибо!** Заявка сохранена, анализ выполняется в фоне. Приглашение определяет сотрудник музея, а не AI.

Можно сделать перерыв: ответы сохраняются после каждого сообщения. **Начать** продолжает с текущего вопроса, **Статус** показывает состояние, **Помощь** объясняет команды. Повторный старт не удаляет ответы и не создаёт вторую заявку в том же наборе. Документы и резюме загружать не нужно: бот принимает текст.

Бот работает в личных сообщениях сообщества «ГИМ» — так устроены боты VK. Ссылку выше можно отправить любому тестировщику. Если кнопки скрыты клиентом VK, используйте `/start`, `/status`, `/help`.
