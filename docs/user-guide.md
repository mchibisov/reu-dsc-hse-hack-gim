# Кандидату в волонтёры ГИМ

1. Откройте [страницу запуска](https://gim-volunteer-bot.vercel.app) или [диалог бота](https://vk.me/club242476311), разрешите сообщения и нажмите **«Начать»**. Бот работает в личных сообщениях сообщества; отдельного пользовательского аккаунта бота не требуется.
2. Прочитайте согласие. Без согласия заполнение не продолжается. Для участия требуется возраст 18+; вводите полную дату рождения.
3. Ответьте на музейные вопросы. Бот показывает прогресс и сохраняет каждый ответ. Где поле неприменимо, напишите «не относится». Для ссылки VK можно нажать «Использовать мою страницу» — профиль не просматривается.
4. Выберите одно или несколько из пяти направлений либо «не определился». Бот расскажет реальные задачи и спросит, совпадают ли они с ожиданиями и интересны ли альтернативы. Отказ от альтернатив не означает автоматический отказ.
5. Ответьте на несколько коротких персональных уточнений. Их максимум три; если AI недоступен, бот использует музейную библиотеку. Ориентир — 5–7 минут без гарантии: подробные ответы занимают больше времени.
6. Дождитесь **«Анкета получена. Спасибо!»**. Куратор получит уведомление и изучит анкету. Внутренние оценки и AI-отчёт кандидату автоматически не показываются; решение принимает сотрудник.

Прервались — отправьте `/start`: сохранённое прохождение продолжится. `/status` показывает состояние, `/help` — помощь. При неверном email или дате бот попросит исправить ответ. Повторно отправлять всю анкету не нужно. Если анализ AI временно недоступен, завершённая анкета остаётся сохранённой.

Содержательные ответы анализируются AI. Имя, контакты и дата рождения исключаются из запроса модели; не добавляйте ненужные личные сведения в свободный текст. Автоматического просмотра страницы VK нет. Для полного удаления данных обратитесь к оператору сообщества.

Дождитесь вопроса перед следующим ответом. Если сообщение, написанное до следующего вопроса, придёт с задержкой, бот определит исходный вопрос по порядку сообщений VK и сохранит дополнение к нему.
