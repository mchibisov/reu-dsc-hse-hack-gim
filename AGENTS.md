# Правила MVP ГИМ

Работай по `docs/specs/S002-gim-vk-bot.md` и связанному плану. Язык — русский. Разработка авторизована пользователем после опроса требований. Пять фиксированных групп критериев, без просмотра профиля ВК, сайта, PDF, загрузки резюме и ручных правок оценки. Отказ LLM оставляет анкету без аналитики, балл отсутствует. Не коммить секреты или реальные анкеты. Отчёты сохраняй в `results/`, гипотезы — в `docs/hypotheses.md`. Все проверки должны иметь фактические результаты и ограничения. Собственная ветка — `codex/gim-mvp`.
