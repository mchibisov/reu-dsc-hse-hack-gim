# Публикация и переносимый контекст

Запрос пользователя: отправить всё актуальное в репозиторий, перечислить выполненное и создать самодостаточный HANDOFF для нового чата. База перед изменением5717750; runtime в этом шаге не меняется, тесты приложения без новой причины не повторяются. HANDOFF переписан с приоритетом текущего состояния; старая история доступна в Git/отчётах.

В публикацию входят HANDOFF, ранее незакоммиченная проверка целевого диалога S011-02 и журнал. Локальные.env, runtime, секреты и ID тестового аккаунта исключаются; actor сохранён только в ignored.runtime для продолжения на исходной машине. Проверки перед commit: относительные ссылки handoff, отсутствие токена и actor ID в публикуемых файлах, git diff --check, сохранённый tag и список staged. После push подтвердить remote main. Полный live VK всё ещё ожидает пользовательское «Начать» и подключение runtime для обновления облака.
