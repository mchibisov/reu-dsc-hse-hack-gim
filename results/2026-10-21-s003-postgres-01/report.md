# S003: изолированная PostgreSQL

Для проверки создан отдельный кластер в игнорируемом `runtime/pgtest`, PostgreSQL18.4, слушает только 127.0.0.1:55439; база `gim_private_test`. Реальные данные и облачная БД не использовались.
`initdb` и `pg_ctl` успешны: [initdb](initdb.log), [start](start.log). Исходный комбинированный shell остался ждать дочерний процесс после pg_ctl; создание БД и миграции выполнены отдельно.
Пять миграций private schema применены без ошибок: [migrate](migrate.log). Это локальный PostgreSQL18.4, не облачный Supabase17.11.
