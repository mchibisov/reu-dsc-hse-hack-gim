# S003: исправление UTF8 миграционного loader

Сквозной тест обнаружил неверные русские ключи JSON в export_bundle: `Path.read_text()` использовал Windows cp1251 для UTF8 SQL. Исправлен только Python loader, тексты четырёх применённых миграций не изменены.
После остановки тестов пересоздана только disposable база `gim_private_test` на localhost55439. Пять миграций повторно применены без ошибок: [лог](migrate.log). Последующие service/database проверки подтвердили русские ключи и непустой XLSX.
Изменение loader само по себе не исправляет ранее повреждённую БД; здесь исправление выполнено пересозданием исключительно локальной тестовой базы. Облачная БД не изменялась.
