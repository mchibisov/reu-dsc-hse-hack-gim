## Независимое ревью

Использован reviewer по Superpowers. Подтверждённое важное замечание «бот может вернуть submitted в draft» воспроизведено падающим тестом и исправлено в третьей миграции. Отзыв подписки дополнительно проверяется хелпером непосредственно перед внешней отправкой; есть регрессионный тест.

Не оценивались ревьюером внешние обработчики, полный цикл signed URL и качество модели: этих компонентов/секретов в его контуре не было. Это остаётся проверкой команды интеграции. Конкурентный отзыв не может отменить уже выполняющийся HTTP-запрос; выданная URL живёт до TTL.

## Не проверено и что нужно команде

- Не запускался полный Python runtime против облака: пароль БД/service LOGIN и Storage service key не предоставлялись. SQL smoke в облаке выполнен через Supabase plugin, локальный тест не выдаётся за облачный.
- Не измерены cloud 50 concurrent, полный VK/LLM pipeline, качество уточнений/экспертное совпадение, HA/PITR, реальное восстановление резервных копий. Нет обещаний по этим метрикам.
- Storage bucket/privacy проверены Dashboard+SQL. Service-key HTTP upload/download/sign flow покрыт локальным HTTP-contract тестом, но не реальным облачным объектом.
- Для бота ветки Vova требуется адаптация к новому контракту и отключение его прежних jobs-воркеров при переходе; детали в integration-with-bot.md.
- Нужны настоящий group ID/проверенный первый admin VK ID, утверждённые рубрика/формула 0–3 и task descriptions, секреты сервисов, модули обработчиков VK/LLM/экспорта, место запуска Python/Redis. После настройки провести облачный integration/load test.
- У ARQ 0.28.0 с redis 5.3.1 в интеграционном shutdown есть upstream DeprecationWarning об использовании close вместо aclose. Он не влияет на результаты; сторонний код не переписан.

## Решения при исполнении

- Поскольку repository пуст, созданы минимальные Python package/migration runner и Docker configuration; несвязанных сервисов нет.
- Временные локальные тестовые БД пересоздавались для проверки миграций с нуля. Избыточный постоянный grant с ADMIN OPTION был отклонён auto-review; из итоговой миграции удалён. Проверка ограничена временной транзакцией и откатилась.
- Никакие произвольные веса критериев не объявлены музейными. Без approved_by/scoring_rule loader не создаёт рабочую конфигурацию.
- Реальные исторические данные подготовлены только локально вне Git; облако не получает их автоматически.
