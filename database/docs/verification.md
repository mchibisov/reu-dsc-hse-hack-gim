# Проверка БД

Актуальные результаты объединённого MVP: [проверка интеграции](../../docs/integration.md).

Миграции проверяются на отдельной PostgreSQL: 13 private-таблиц, роли бота/воркера/сотрудника, RLS, неизменяемые снимки, проверка цитат, ручная оценка с приоритетом, идемпотентность, 50 параллельных кандидатов, аренды и повторы задач, ACL экспорта и Storage-адаптеры.

Исторические отчёты не заменяют проверку конкретного развёрнутого стенда. Эта интеграция не меняет рабочую Supabase БД и не подтверждает её текущую конфигурацию.
